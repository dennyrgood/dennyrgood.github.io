# Reset and Migrate MacBook Air (M3)

This document summarizes the correct process to reset a previously used
MacBook Air (M3) to factory condition and migrate data from an existing
MacBook Air (M2).

## 1. Factory Reset the M3 (Required)

Use Apple's Erase Assistant to fully remove the prior owner and return
the Mac to a factory-like state:\
\
• Log in to any admin account on the M3\
• Open System Settings → General → Transfer or Reset\
• Select Erase All Content and Settings\
• Confirm and allow macOS to reinstall\
\
This removes all users, data, iCloud accounts, and Activation Lock.

## 2. Migrate Data from the M2

After reset, the M3 will restart to the setup screen:\
\
• During setup, choose Transfer information from another Mac\
• On the M2, open Migration Assistant and select To another Mac\
• Connect via Thunderbolt/USB-C (fastest) or Wi-Fi\
• Transfer user accounts, applications, settings, and data

### Alternative: Time Machine Restore

If preferred, create a fresh Time Machine backup on the M2 and restore
from it during M3 setup.

## 3. Post-Migration Checks

After migration:\
\
• Confirm FileVault and security settings\
• Launch key apps (Rosetta installs automatically if needed)\
• Verify iCloud, Mail, and Messages sync correctly

## Summary

Erase All Content and Settings → Setup Assistant → Migration Assistant.
This results in a clean M3 with all data and settings from the M2,
without any trace of the previous user.
